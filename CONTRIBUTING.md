# Project Collaboration & Contributing Guidelines

## Team Workflow
1. All changes must be developed on a dedicated branch (`dev` or `feature/...`).
2. Never push directly to `main`.
3. Submit all changes through a GitHub Pull Request.

## Commit Guidelines
Use semantic commit prefixes:
- `feat:` for new capabilities
- `docs:` for documentation updates
- `fix:` for bug fixes

## Team Roles & Tasks
- **Contributor 1 (Lead Developer):** Project architecture and code review.
- **Contributor 2 (Feature Developer):** Feature implementation and documentation.
